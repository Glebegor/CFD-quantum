
# ISLBM Cylinder CFD Solver

High performance C++20 implementation of
Interpolation-Supplemented Lattice Boltzmann Method.

## Features

- D2Q9 lattice
- BGK collision operator
- ISLBM off-lattice streaming
- Cylinder no-slip boundary
- Structure-of-arrays memory layout
- OpenMP parallel kernels
- VTK output for ParaView
